# hxyfront-62008 烟花燃放脚本编排 · 设备排程工作台

面向烟花燃放编排师的设备排程前端工具：把“纸笔决定哪一发接哪台点火器”的工作补成可视化设备排程。

## 排程规则

- **四台点火器（F1–F4）**：各有冷却时间（同设备相邻两次点火的最小间隔）与供电档位（允许的同时耗电总功率 kW）。
- **点火节点**：带点火时刻、持续时长与耗电级别（L1=2kW / L2=4kW / L3=6kW），按点火时刻逐发排入。
- **排入选择**：按设备编号顺序选择第一台“冷却已结束且叠加后不会超过总功率档位”的点火器。
- **冲突停止**：找不到可用设备时，排程停在该冲突节点，之后的节点保持顺序、标记为“停止未排入”；冲突面板逐台说明设备占用时段、冲突时刻功率与不可承接原因。
- **停用改派**：在设备架上停用点火器后，该设备上的节点进入“等待改派”，系统按发次顺序尝试改派到其它设备，其余节点的派工与顺序不动；找不到目标则持续“等待改派”。

## 页面模块

- 设备架：冷却时间 / 供电档位 / 在用-停用开关
- 时间轴编排：四台设备泳道的占用甘特图 + 待派泳道 + 排程停止线 / 播放头
- 冲突诊断：停止节点与每台设备占用时段
- 执行单：按发次列出设备编号、状态（已排入 / 已改派 / 等待改派 / 停止未排入）
- 燃放点位平面图：A/B/C 区点位，颜色对应设备，可定位发次并与时间轴、执行单联动
- 整场预览：播放到第一处无法供电（或等待改派）的位置自动停止
